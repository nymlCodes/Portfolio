================================================================================
                    NEYAMUL ISLAM - PORTFOLIO ARCHITECTURE GUIDE
================================================================================

This document provides a comprehensive, file-by-file guide to your portfolio
web application. It explains the project architecture, directory structure,
where every component and utility is placed, how data flows, and how smooth
performance was achieved across all devices (including mobile & low-end devices).

================================================================================
1. TECH STACK & CORE DEPENDENCIES
================================================================================
- Framework: Next.js 14.2.3 (App Router architecture)
- Language: TypeScript 5.4.5 (Strict type checking)
- UI & Components: React 18, Motion (framer-motion v12)
- Styling: Tailwind CSS 3.4.1 + Custom Hardware-Accelerated CSS
- Icons: Lucide React (v1.23.0) & React Icons (v5.6.0)
- Deployment Target: Vercel / Node.js Hosting

3. DETAILED FILE BREAKDOWN & RESPONSIBILITIES
================================================================================

--------------------------------------------------------------------------------
A. TYPES LAYER (`src/types/index.ts`)
--------------------------------------------------------------------------------
- Purpose: Centralizes all TypeScript interfaces to ensure strict type safety across
  the codebase.
- Defined Interfaces:
  * `Project`: Represents a full project item (title, thumbnail, description,
    technologies, features, errors, lessonsLearned, futurePlans, liveUrl, githubUrl, etc.)
  * `ProjectError`: Structure for challenge/solution pairs in project details.
  * `IntroStage`: String union ('idle' | 'entering' | 'focus' | 'collapsing' | 'completed')
    driving the navigation intro sequence.
  * `QuickFact`: Badges displayed on the About page.
  * `EducationItem`: Academic background degree information.
  * `CourseData` & `CourseSkill`: Online course structures.
  * `CertificateItem`: Online certificate links and badges.
  * `GoalItemData`: Self-learning roadmap checklist.
  * `SkillItem` & `SkillGroup`: Categorized skills (Frontend, Backend, Tools) with proficiency %.
  * `ToolItem`: Icon components and brand colors for tools orbit.

--------------------------------------------------------------------------------
B. DATA FETCHING LAYER (`src/lib/`)
--------------------------------------------------------------------------------
1. `src/lib/projects.ts`
   - Server-side function `getProjects()`
   - Fetches the project list from `${NEXT_PUBLIC_SERVER_URL}/projects` with `no-store` cache.
   - Robust URL handling: Automatically handles missing/extra slashes and gracefully
     returns empty array `[]` on connection errors without breaking the site.

2. `src/lib/getProjectById.ts`
   - Server-side function `getProjectById(id: string)`
   - Fetches a specific project by its ID from `${NEXT_PUBLIC_SERVER_URL}/projects/${id}`.
   - Returns typed `Project` object or `null` if not found.

--------------------------------------------------------------------------------
C. APP ROUTER PAGES (`src/app/`)
--------------------------------------------------------------------------------
1. `src/app/layout.tsx`
   - Root layout component wrapping all pages.
   - Loads the Google Font "Inter" (weights 300 to 900).
   - Injects global metadata (Title, Description, Favicon).
   - Wraps page children inside `HomeClient`.

2. `src/app/loading.tsx`
   - Next.js loading UI fallback.
   - Features ambient purple glow, rotating dual rings, and animated "N" logo.

3. `src/app/page.tsx`
   - Home landing page route (`/`). Renders `<Hero />`.

4. `src/app/about/page.tsx`
   - About page route (`/about`). Renders `<About />`.

5. `src/app/skills/page.tsx`
   - Skills page route (`/skills`). Renders `<Skills />`.

6. `src/app/education/page.tsx`
   - Education page route (`/education`). Renders `<Education />`.

7. `src/app/projects/page.tsx`
   - Projects list page route (`/projects`). Renders `<Projects />`.

8. `src/app/contact/page.tsx`
   - Contact page route (`/contact`). Renders `<Contact />`.

9. `src/app/details/[id]/page.tsx`
   - Dynamic project details route (`/details/:id`).
   - Server Component that extracts the `id` param, calls `getProjectById(id)`,
     and passes the result to `ProjectDetailsClient`.

--------------------------------------------------------------------------------
D. GLOBAL UI COMPONENTS (`src/components/`)
--------------------------------------------------------------------------------
1. `src/components/HomeClient.tsx`
   - State Orchestrator: Controls the lifecycle of the user experience.
   - Manages `splashDone` and `introStage`.
   - Renders `SplashScreen` -> `PortfolioIntro` -> `AnimatedBackground` -> `Cursor` -> `RouteSwitch`.

2. `src/components/SplashScreen.tsx`
   - Displayed for ~2.2s upon first entering the site.
   - Displays welcome greeting and animated name headline before smoothly fading out.
   - Disables scroll during display and cleanly restores it on unmount.

3. `src/components/PortfolioIntro.tsx`
   - Timed controller for guiding user attention to navigation on initial visit.
   - Stages: 'entering' (0ms) -> 'focus' (1650ms) -> 'collapsing' (3250ms) -> 'completed' (3750ms).

4. `src/components/AnimatedBackground.tsx`
   - Renders 3 floating glowing orbs + grid background + floating particles.
   - Uses deterministic positioning and GPU hardware acceleration.
   - Automatically optimizes particle count on mobile screens (10 particles vs 35 on desktop)
     and disables particles if the user has `prefers-reduced-motion` enabled.

5. `src/components/Cursor.tsx`
   - Custom bold interactive cursor for desktop mouse/trackpad users.
   - Features a 10px glowing center dot, a 38px outer magnetic ring with breathing drop-shadow pulse,
     and 8 cascading trail dust particles with rich purple luminescence.
   - Fluid, slower physics with micro-gliding and magnetic float lag.
   - Automatically disabled on touch screens and mobile devices (`(pointer: fine)` check).

6. `src/components/ProjectCard.tsx`
   - Interactive card displaying project thumbnail, status badge (Live/In Progress),
     category, title, description, top 3 tech tags, and a "View Details" action link.
   - Features animated spinning border glow on hover.

7. `src/components/ProjectsClient.tsx`
   - Responsive grid wrapper (1 col mobile, 2 col tablet, 3 col desktop) for ProjectCard list.
   - Includes link button to the user's GitHub profile.

8. `src/components/ProjectDetailsClient.tsx`
   - Comprehensive case-study view for an individual project.
   - Sections: Hero image with scan-line animation, Live Demo / Client Code / Server Code buttons,
     Tech stack tags, Feature list with SpotlightCards, Challenges & Solutions,
     Lessons Learned, and Future Plans.

4. PERFORMANCE & MOBILE SMOOTHNESS ENHANCEMENTS
================================================================================

Low-end devices and mobile browsers previously struggled with jitter/lag due to
several browser rendering bottlenecks. The following targeted fixes were implemented:

1. GPU Layer Promotion & Hardware Acceleration:
   - Elements with continuous animation now utilize `transform: translate3d(0,0,0)`
     or `transform: translateZ(0)` and `backface-visibility: hidden`.
   - This moves rendering calculations to the GPU compositor thread, avoiding CPU repaint
     cycles during touch-scrolling.

2. Reduced Blur Computation on Mobile:
   - High CSS blur values (e.g. `blur(90px)-blur(120px)`) force intense software rasterization
     on mobile GPUs.
   - On screens `<= 768px`, blur radiuses are scaled down (e.g. `blur(35px)`), retaining the
     exact glowing aesthetic while boosting scroll framerate from ~25fps to a silky 60+ fps.

3. Touch-Safe Event Listeners:
   - On desktop, `onMouseMove` computes 3D card tilt and spotlight positions using
     `getBoundingClientRect()`.
   - On mobile/touch devices, touch scrolling fires `mousemove` events which caused layout
     thrashing. All mousemove handlers now check `window.matchMedia('(pointer: fine)')`,
     completely eliminating touch-scroll calculation overhead.

4. Universal Smooth Scroll Scope Fix:
   - Universal `* { scroll-behavior: smooth; }` was refined to `html { scroll-behavior: smooth; }`.
   - This prevents internal scroll containers from fighting native touch momentum on iOS and Android.

5. Adaptive Particle Load:
   - Particle generation is reduced to 10 lightweight particles on mobile (down from 60),
     and completely disabled when the operating system requests `prefers-reduced-motion`.

5. HOW TO RUN & DEVELOP LOCALLY
================================================================================
- Install dependencies:
  $ npm install

- Run development server:
  $ npm run dev
  (Access at http://localhost:3000)

- Type check:
  $ npx tsc --noEmit

- Production build & test:
  $ npm run build
  $ npm start
